# OffClock · 퇴근시계

Windows 작업표시줄에서 퇴근까지 남은 시간을 보여주는 작은 위젯입니다.

## 사용법

[릴리스](https://github.com/yoyowasi/OffClock/releases/latest)에서 `OffClock.zip`을 받아 압축을 풀고 `OffClock.exe`를 실행하세요. 위젯을 클릭하면 근무 시간, 표시 형식, 모니터, 테마, 무음 알림, 로그인 시 자동 시작을 설정할 수 있습니다.

- **오늘 급여**를 선택하고 세전 연봉을 원 단위로 입력하세요. 입력칸 아래에서 한글 금액을 바로 확인할 수 있습니다. 추정 일당은 연봉 ÷ 12 ÷ 해당 월의 월~금 일수입니다. 출근부터 퇴근까지 0원에서 이 금액까지 올라갑니다. 토·일은 0원이며, 평일 공휴일과 휴게 시간은 따로 계산하지 않습니다. 연봉은 PC에만 저장됩니다.
- 위젯을 눌러 설정에서 **업데이트 확인**을 열면 새 버전의 변경 내용을 볼 수 있습니다. **지금 설치**를 선택하면 앱이 다시 실행되고 릴리스 노트가 한 번 표시됩니다. **자동 업데이트**를 켜고 저장하면 설치도 자동으로 진행됩니다. 기본값은 꺼짐입니다. 두 방식 모두 비공개 저장소에 접근 가능한 GitHub CLI 로그인이 필요합니다.

## 빌드

64비트 Windows의 PowerShell에서 아래 명령을 실행하면 `outputs/OffClock.exe`가 생성됩니다.

```powershell
.\src\Build.ps1
.\src\VerifyClock.ps1
```
