# OffClock · 퇴근시계

Windows 작업표시줄에서 퇴근까지 남은 시간을 보여주는 작은 위젯입니다.

## 사용법

[릴리스](https://github.com/yoyowasi/OffClock/releases/latest)에서 `OffClock.zip`을 받아 압축을 풀고 `OffClock.exe`를 실행하세요. 위젯을 클릭하면 근무 시간, 표시 형식, 모니터, 테마, 무음 알림, 로그인 시 자동 시작을 설정할 수 있습니다.

- **점심시간**을 켜고 시작·끝 시간을 정하면 오전에는 점심까지, 점심 중에는 점심 끝까지, 오후에는 퇴근까지 남은 시간을 셉니다. 점심 동안 진행 막대와 오늘 급여는 멈추고, 퇴근 알림을 켜 두면 점심 시작과 끝나기 5분 전에도 알려 줍니다.
- **테마**는 다크·라이트, 벚꽃·바다·숲·노을 색 테마, 고양이·곰·토끼·펭귄·병아리 캐릭터 테마 중에서 고를 수 있습니다. 캐릭터는 퇴근 30분 전부터 볼이 물들고, 10분 전부터 땀을 흘리고, 퇴근하면 웃습니다.
- **진행 막대 표시** 옆의 **색 변경**으로 막대 색을 직접 고를 수 있습니다. **기본값**을 누르면 테마 색(남은 시간에 따라 바뀌는 색)으로 돌아갑니다.
- **오늘 급여**를 선택하고 세전 연봉을 원 단위로 입력하세요. 입력칸 아래에서 한글 금액을 바로 확인할 수 있습니다. 추정 일당은 연봉 ÷ 12 ÷ 해당 월의 월~금 일수입니다. 출근부터 퇴근까지 0원에서 이 금액까지 올라가며, 점심시간을 켜면 그동안은 멈춥니다. 토·일은 0원이며, 평일 공휴일은 따로 계산하지 않습니다. 연봉은 PC에만 저장됩니다.
- 위젯을 눌러 설정에서 **업데이트 확인**을 열면 새 버전의 변경 내용을 볼 수 있습니다. **지금 설치**를 선택하면 앱이 다시 실행되고 릴리스 노트가 한 번 표시됩니다. **자동 업데이트**를 켜고 저장하면 설치도 자동으로 진행됩니다. 기본값은 꺼짐입니다. 두 방식 모두 비공개 저장소에 접근 가능한 GitHub CLI 로그인이 필요합니다. 설치에 실패하면 이전 버전으로 돌아온 뒤 원인을 한 번 알려 주고, 자동 업데이트는 그 버전을 다시 받지 않습니다. 같은 버전은 **업데이트 확인**에서 직접 다시 설치할 수 있습니다.

## 빌드

64비트 Windows의 PowerShell에서 아래 명령을 실행하면 `outputs/OffClock.exe`가 생성됩니다.

```powershell
.\src\Build.ps1
.\src\VerifyClock.ps1
```
