# OffClock · 퇴근시계

Windows 작업표시줄에서 퇴근까지 남은 시간을 보여주는 작은 위젯입니다.

## 사용법

[릴리스](https://github.com/yoyowasi/OffClock/releases/latest)에서 `OffClock.zip`을 받아 압축을 풀고 `OffClock.exe`를 실행하세요. 위젯을 클릭하면 설정 창이 열립니다. 설정은 **근무**(출근·퇴근, 점심, 근무 요일, 공휴일, 월급날), **표시**(표시 형식, 모니터, 테마, 투명도, 진행 막대, 초과 근무), **알림·기타**(무음 알림, 로그인 시 자동 시작, 연봉, 업데이트) 탭으로 나뉩니다. 위젯을 오른쪽 클릭하면 표시 형식, 테마, 오늘만 변경을 바로 고를 수 있고, 마우스를 올리면 오늘 근무 시간, 진행률, 다음 알림, 다음 공휴일이 보입니다.

- **점심시간**을 켜고 시작·끝 시간을 정하면 오전에는 점심까지, 점심 중에는 점심 끝까지, 오후에는 퇴근까지 남은 시간을 셉니다. 점심 동안 진행 막대와 오늘 급여는 멈추고, 퇴근 알림을 켜 두면 점심 시작과 끝나기 5분 전에도 알려 줍니다.
- **근무 요일**(기본 월~금)이 아닌 날과 공휴일에는 위젯에 쉬는 날이라고 표시하고 알림을 울리지 않습니다. 2026~2028년 공휴일(대체공휴일, 노동절·제헌절, 선거일 포함)이 들어 있으며, 2028년은 공식 월력요항이 나오기 전 자료입니다. **공휴일에 쉬기**를 끄면 공휴일도 근무일로 셉니다.
- **휴일 편집…**을 누르면 `%LOCALAPPDATA%\OffClock\holidays.txt`가 메모장으로 열립니다. `2027-03-15 창립기념일`처럼 쓰면 쉬는 날이 늘고, `-2027-06-03`처럼 앞에 `-`를 붙이면 그 공휴일에 출근하는 것으로 셉니다. 저장하면 1분 안에 반영됩니다.
- **오늘만 변경**(위젯 오른쪽 클릭 또는 트레이 메뉴)에서 오전 반차, 오후 반차, 오늘 쉬기, 시간 직접 입력을 고르면 그날만 적용되고 다음 날 원래대로 돌아옵니다. 반차는 점심을 뺀 근무 시간의 절반입니다. 예를 들어 9~18시에 점심 12~13시면 오전 반차는 14시 출근, 오후 반차는 14시 퇴근입니다. 쉬는 날에 시간을 입력하면 그날은 근무일이 됩니다. 야간 근무(퇴근 시간이 출근 시간보다 이른 경우)에서는 쓸 수 없고, 시간 직접 입력은 자정을 넘길 수 없습니다.
- **알림 편집…**(알림·기타 탭)을 누르면 `%LOCALAPPDATA%\OffClock\reminders.txt`가 열립니다. `17:30 일일 보고 쓰기`처럼 시각을 쓰거나, `퇴근-30 타임시트 입력`, `출근+10 메일 확인`처럼 출근·퇴근 기준 분을 쓰면 근무일마다 무음 알림을 띄웁니다. 출근·퇴근 기준 알림은 반차와 오늘만 변경을 따라갑니다. 잠자기 등으로 놓친 알림은 10분 안에만 늦게 띄웁니다.
- **퇴근 후 초과 근무 시간 표시**를 켜면 퇴근 시간이 지난 뒤 지난 시간을 `+`를 붙여 이어서 보여 줍니다.
- **월급날**을 고르고 표시 형식을 **월급날 D-day**로 바꾸면 월급날까지 남은 날을 보여 줍니다. 그 달에 없는 날(예: 31일)은 말일로, 주말·공휴일이면 그 전 평일로 셉니다.
- **테마**는 다크·라이트, 벚꽃·바다·숲·노을 색 테마, 고양이·곰·토끼·펭귄·병아리 캐릭터 테마 중에서 고를 수 있습니다. 캐릭터는 퇴근 30분 전부터 볼이 물들고, 10분 전부터 땀을 흘리고, 퇴근하면 웃습니다.
- **진행 막대 표시** 옆의 **색 변경**으로 막대 색을 직접 고를 수 있습니다. **기본값**을 누르면 테마 색(남은 시간에 따라 바뀌는 색)으로 돌아갑니다.
- **오늘 급여**를 선택하고 세전 연봉을 원 단위로 입력하세요. 입력칸 아래에서 한글 금액을 바로 확인할 수 있습니다. 추정 일당은 연봉 ÷ 12 ÷ 그 달의 근무일 수(근무 요일에서 쉬는 공휴일을 뺀 날)입니다. 출근부터 퇴근까지 0원에서 이 금액까지 올라가며, 점심시간을 켜면 그동안은 멈춥니다. 쉬는 날은 0원입니다. 연봉은 PC에만 저장됩니다.
- 위젯을 눌러 설정에서 **업데이트 확인**을 열면 새 버전의 변경 내용을 볼 수 있습니다. **지금 설치**를 선택하면 앱이 다시 실행되고 릴리스 노트가 한 번 표시됩니다. **자동 업데이트**를 켜고 저장하면 설치도 자동으로 진행됩니다. 기본값은 꺼짐입니다. 두 방식 모두 인터넷 연결만 있으면 되고 GitHub CLI나 로그인은 필요 없습니다. 1.5.0 이하는 아직 GitHub CLI로 업데이트하므로, GitHub CLI가 없으면 최신 버전을 릴리스에서 한 번 직접 받으세요. 설치에 실패하면 이전 버전으로 돌아온 뒤 원인을 한 번 알려 주고, 자동 업데이트는 그 버전을 다시 받지 않습니다. 같은 버전은 **업데이트 확인**에서 직접 다시 설치할 수 있습니다.
- 오류가 생기면 `%LOCALAPPDATA%\OffClock\offclock.log`에 기록됩니다.

## 빌드

64비트 Windows의 PowerShell에서 아래 명령을 실행하면 `outputs/OffClock.exe`가 생성됩니다.

```powershell
.\src\Build.ps1
.\src\VerifyClock.ps1
```
